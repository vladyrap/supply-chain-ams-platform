## Regla de oro
La **evidencia** prevalece sobre la inferencia. La **arquitectura** prevalece sobre la
velocidad. El **conocimiento** pertenece a la organización. Todo cambio significativo pasa por
el Gate de Gobierno antes de implementarse.
