# 📺 TV Mode · Manual cliente

> **Ruta:** `/tv` · **Para quién:** Todos (pantalla de display)

## ¿Qué hace?

Modo TV de gran formato para colgar en pared/monitor del equipo. Rotación automática de pantallas:
1. KPIs principales
2. Top tickets P1 activos
3. Ranking consultores del día
4. Mapa de calor SAP
5. Stream de últimos eventos
6. Mensaje motivacional / quote del día

Cada pantalla 15-20 seg, rotación infinita.

## Cuándo abrirlo

- Pantalla en sala del equipo
- Sala de reuniones para reviews
- Pantalla en oficina del sponsor del cliente
- Open space para visibilidad de la operación

## Cómo usar

- Abrir en navegador full-screen (F11)
- Auto-rotación automática
- Click pausa rotación si querés quedarte en una
- ESC = vuelve a navegación normal

## Permisos

Cualquier rol (es read-only).

## Qué se guarda

Nada. Consume snapshots de otros módulos.

## Limitaciones

- Requiere refresh manual si cambian permisos
- Optimizado para 16:9 (1920×1080, 4K también)
- Sin sonido (mute para ambiente)
